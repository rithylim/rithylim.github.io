Overview

This project is a compact 4-layer motor driver PCB designed to control a 3-phase brushless DC (BLDC) motor. The board integrates gate drivers, current sensing resistors, and protection circuitry into a single board, reducing wiring complexity for robotics and UAV applications.

The design went through two revisions — the first revision identified a ground plane issue causing switching noise; the second revision fixed this with improved via stitching and copper pour separation.

Key Features

  • 4-layer stackup: Signal / GND / Power / Signal for low EMI
  • Integrated DRV8323 gate driver with SPI configuration
  • 3-phase shunt current sensing (0.01 Ω, 1% tolerance)
  • Onboard 5V / 3.3V LDO for MCU and logic supply
  • Reverse polarity and overvoltage protection
  • JST connectors for motor phase and power input

Challenges & Lessons Learned

Ground bounce on first revision: High-side gate driver switching caused voltage spikes on the analog ground reference. Fixed by separating AGND and PGND planes and connecting them at a single star point.

Thermal management: The gate driver package required a thermal via array under the exposed pad. Added 16× 0.3mm vias to the internal ground plane to meet the thermal resistance target.
